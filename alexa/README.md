# Skill Tendedero inteligente — práctica 4

El [modelo de interacción es-MX](interaction-model-es-MX.json) contiene la invocación `tendedero inteligente`, nueve intents funcionales, el tipo `CondicionSensor` y el diálogo que pide y confirma el código de vinculación.

La Skill utiliza **Custom** y **Provision your own backend resources**. En Build → Endpoint se configura el ARN de la Lambda del equipo.
